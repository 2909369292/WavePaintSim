### 关键技术（解混淆管线）
1. **识别 stringArray 机制**：解码器 `_0x55bf(idx)`（offset=128，元素 base64）+
   工厂 `_0x3f97()` + 顶部 rotate IIFE。三者自包含。
2. **解码环境抽取**：escodegen 把 [fn _0x3f97, fn _0x55bf, rotateIIFE] 三个 AST
   节点重生成独立代码 → node:vm 执行 → 得到 lookup(idx)。
3. **AST 遍历替换**（acorn parse + 父引用就地替换）：
   - 别名链收集（1742 个 =_0x55bf 别名）
   - 数值对象字面量映射（832 个 const X={a:0x..}）
   - **19090 处解码调用全部替换为字符串字面量，失败 0**
4. **escodegen 重生成**：自动 hex→十进制 + 缩进 33K 行。
5. **不做控制流平坦化还原**（保行为等价）；解码器/数组保留兜底。

### 复用教训
- **obfuscator.io 字符串还原**：不需要完整解混淆，只要把「解码器+工厂+rotate
  IIFE」三段 AST 抽出来在 vm 跑，就能对全文件所有调用点解码。比逆 rotate 简单。
- **AST 就地替换需父引用**：递归 walk 时传 (parent, key, idx)，替换 `parent[key][idx]`
  或 `parent[key]`。
