### 关键技术（解混淆管线）
1. **识别 stringArray 机制**：解码器 `_0x55bf(idx)`（offset=128，元素 base64）+
   工厂 `_0x3f97()` + 顶部 rotate IIFE。三者自包含。
2. **解码环境抽取**：escodegen 把 [fn _0x3f97, fn _0x55bf, rotateIIFE] 三个 AST
   节点重生成独立代码 → node:vm 执行 → 得到 lookup(idx)。
3. **AST 遍历替换**（acorn parse + 父引用就地替换）：
   - 别名链收集（1742 个 =_0x55bf 别名）
   - 数值对象字面量映射（832 个 const X={a:0x..}）
   - **19090 处解码调用全部替换为字符串字面量，失败 0**
4. **escodegen 重生成**：自动 hex→十进制 + 缩进 33K 行。
5. **不做控制流平坦化还原**（保行为等价）；解码器/数组保留兜底。

### 行为一致性验证（Edge headless + CDP）
- 全局 API 两侧一致；**画布 wave-canvas.toDataURL() hash 完全相同**
- 信号 clk:bit:60 一致；控制台 0 错误；select 单击框选 [4,5] + 工具条正常

### 复用教训
- **obfuscator.io 字符串还原**：不需要完整解混淆，只要把「解码器+工厂+rotate
  IIFE」三段 AST 抽出来在 vm 跑，就能对全文件所有调用点解码。比逆 rotate 简单。
- **AST 就地替换需父引用**：递归 walk 时传 (parent, key, idx)，替换 `parent[key][idx]`
  或 `parent[key]`。
- git 历史怪癖再确认：commit 输出 "could not read log file"/"nothing added"
  但实际成功（9dcc034/03fdd7c）。以 `git log` 为准。
- Write 工具向含中文的深层路径写文件可能失败（.git-msg-tmp.txt 两次丢失）；
  改用 bash printf > 相对 ASCII 路径（如 clean-msg.txt）成功。
- node_modules 需 .gitignore；acorn/escodegen 是 CJS，ESM 里用 createRequire。

## WavePaintClean exe 打包（父级 git 52d32d9）

用户要求：与 WavePaintSim 一样把 WavePaintClean（解混淆核心 + 功能代码）封装为
**任何装有 Edge 的 Windows 电脑可独立运行**的 exe，用户将验证解混淆功能完整性。

### 做法
- 从 WavePaintSim 复制 WavePaintLauncher.cs / build.ps1 / ivl.zip → WavePaintClean
- **改名**：所有 WavePaintSim → WavePaintClean（%TEMP% 目录、mutex、
  port/log 文件前缀、快照目录）；build.ps1 out:WavePaintClean.exe
- **build.ps1 排除源混淆核心** wavepaint.63e6dade.js（功能由 clean.js 替代，
  否则 exe 多 1.4MB）：`Get-ChildItem -File $pat | Where-Object {...}`
- **编码坑**：cs 原无 BOM 但含中文注释；复制后统一 UTF-8 BOM。
  ⚠ build.ps1 连续 node 写回 '\uFEFF'+ps 会叠 3 个 BOM → 先 while 去 BOM 再补 1 个
  （head -c 3 | od 验证 ef bb bf）
- exe 22,353,920 字节

### exe 验证（Edge headless + CDP 走 exe 的 HTTP 服务）
- 全局 API 就绪；RTL 解析 → clk/rst_n；激励 clk=11001100；仿真
  "Simulation done: 1 signals, tmax 30000"，q 正常计数；控制台 0 异常
- /api/sim 直接 POST @@FILE 格式返回有效 VCD（iverilog 链路 OK）

### 复用要点
- 端口文件 %TEMP%\WavePaintClean_port_<PID>.txt 读端口后 curl/页面验证；
  exe 自动开 Edge --app= 窗口
- 单实例 mutex 阻止二次启动 → 用户验证前我起的实例要 taskkill
- .gitignore 加 WavePaintClean.exe（构建产物不入库，同 WavePaintSim 惯例）
