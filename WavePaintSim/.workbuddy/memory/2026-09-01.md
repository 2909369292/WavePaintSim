- 端到端验证（page-eval 改 clk 破坏交替 + en 全 1）：q 正常计数（与完美交替 sim 一致）。

## 第十六轮：选框受整步/子步粒度控制 + 菜单自动聚焦即输即写（提交 72cf188，exe 22:31）

用户需求（3 条）：
1. 选框**视觉范围**要受整步/子步控制（此前写入按整步、选框按单格，不一致）
2. 框选后弹出的菜单**自动聚焦输入框**：直接输入 → 回车 或 点击别处 → 直接写入，
   不需要点确认/输入值按钮；不输入点别处 = 取消；取消按钮也不要
3. 不需要复制/粘贴按钮（快捷键已够）

### 实现要点（关键：仍完全复用核心原生，不自绘）
- **核心原生 range selection 最小单位是「一格 sample」**，无法直接改粒度。
- 解法：整步粒度时 feature-select **拦截真实鼠标事件**，把坐标按主步边界对齐后
  **派发合成事件给核心**（start 取主步首格、end 取主步末格）→ 核心原生
  range selection 按整步边界绘制。**子步粒度放行真实事件**（按格子画）。
- `replaying` 标志防合成事件递归（合成事件也会触发本模块捕获监听）。
- `alignRegion`：region 也对齐主步边界，写入范围与视觉一致。
- 工具条：仅保留「设1/设0/设x/翻转」+ input；input 自动 focus+select；
  Enter/blur 有值即写入、无值即取消；Esc 取消；点按钮时 suppressCommit
  防止「失焦误提交」。删「输入值」「取消」「复制」「粘贴」按钮。
- 值输入弹窗（Bit/Vector Value）：隐藏核心 #wp-modal 的确定/取消按钮（保留 X），
  Enter/blur 有值即写入、无值即取消，自动聚焦。

### 验证（真实浏览器）
- 整步 sampleStart=4(%2=0)/sampleEnd=13((13+1)%2=0) → 整步对齐 ✓
- 子步 sampleStart=5(%2=1) → 子步级 ✓
- 工具条按钮仅 4 个 + input，focused=true ✓
- 回车写入生效（弹窗改值可见）✓
- 无输入点别处=取消；输入 0 点别处=写入 10 格（整步对齐）✓

### 经验
- 「让核心原生按我们的粒度画」的可行手法：**拦截真实事件 + 派发坐标修正后的
  合成事件**（核心只认事件坐标）。比自绘更符合"完全复用原生"的要求。
- 合成事件必然回流到自己的捕获监听器 → 必须有 replaying 短路标志。

用户反馈（select 工具 + 整步粒度）：
1. 快速拖动时起点若落在整步后半（子步位置），选框仍是子步的，结尾按子步跳动
2. 反向拖动整步边界偏半步
3. 要求：框选模式下单击也算一次框选（一个粒度单位）

### 根因
- **线性反算坐标有累积舍入误差**：之前用「平均格宽 × (target-current)」反推 clientX，
  误差让核心 mapCanvasPosition 拿到相邻格（子步位置）。
- 起点/终点哪个对齐首格、哪个对齐末格**取决于拖动方向**，之前固定 start=首格/end=末格，
  反向拖动就错。

### 修复（feature-select）
- **xForSample**：二分查找精确求使 mapCanvasPosition(x).signalSampleIndex===目标 的 x。
- **方向感知**：mousedown 只记录不派发；第一次 mousemove 确定方向后派发合成 mousedown
  （向右→起点首格；向左→起点末格），当前点对齐另一端；方向一变重派 mousedown。
- **单击**：派发合成 mousedown(首格)+mouseup(末格) → 核心原生画一个粒度单位
  （整步=一个主步，子步=1 格）。
- marquee 增加 startClientX/Y、startSample、dir、sent。

### 验证（真实浏览器）
整步正向快拖（起点奇数 sample）→ sampleStart=0 ✓；整步反向（420→190）→ [4,15] ✓；
整步单击 → 宽2 ✓；子步单击 → 宽1 ✓；子步拖 → 子步级 ✓。

### 教训
- **"反向 null"排查**：是测试坐标落在 SIM 侧边栏覆盖区（.sim-sec-title 盖住画布右侧），
  elementFromPoint 命中非 canvas → onMouseDown 因 e.target!==canvas return。
  不是代码 bug。**测试拖动坐标要避开右侧栏**（或先折叠 SIM 面板）。
- 精确求"某 sample 的像素 x"：**二分 mapCanvasPosition**，比线性反算可靠。
