## 五条不可违背的硬约束

1. **绝不修改 `js/wavepaint.63e6dade.js`**（1.43MB 混淆核心，obfuscator.io）。一切新功能走
   「独立 `js/feature-*.js` 模块 + 捕获阶段事件接管 + 核心暴露的全局 API」。
2. **改完 JS/HTML 必须 `.\build.ps1` 重建 exe**，刷新页面无效。
   ⚠ 常见误判：改了根目录的副本以为改了源码——`build.ps1` 只嵌 `index.html` + `js\*` + `css\*` + `img\*` + `lib\*` + `ivl.zip`。
3. **`csc` 是 .NET 4.0 / C# 4.0**：禁用 `out int x`、`??=`、switch 表达式等 C# 7+ 语法。
4. **数据模型铁律**：`signal.values.length === m_sampleCount × (m_subStepCount + 1)`；
   每步占 `(子步+1)` 个下标，**主值是每步第 1 个**（下标 `步号 × stride`）。
5. **位值编码**：Bit 信号存**数字**（`0`低 `1`高 `-1`x `2`z `3`u `4`d）；Vector 存**字符串**。
   写错类型**不报错**，症状是波形空白或恒 0。
