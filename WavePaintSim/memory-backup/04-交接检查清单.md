### 4. 混淆核心探查方法论

混淆器把字符串拆成 `'m_undoStac'+'k'`、`'pushUndoSn'+'apshot'`、`_0x27d135(0x1773)+'apshot'`
这类形式，**直接 grep 完整属性名结果恒为 0**。

正确做法 —— 搜片段 + 限制输出长度，**绝不要 grep 后直接输出**（1.43MB 单行文件会 dump 上百万字符）：
```bash
python -c "
import re
s=open('js/wavepaint.63e6dade.js',encoding='utf-8',errors='replace').read()
for m in re.finditer('apshot', s):
    print(s[max(0,m.start()-300):m.end()+300].replace(chr(10),' '))
"
```
**优先做运行时验证**（浏览器控制台），比静态推测可靠得多。

## 三、核心 API 速查

| 全局 | 说明 |
|---|---|
| `window.Signal` / `SignalType` / `Radix` / `DriveStrength` / `SegmentStyle` | 类与枚举 |
| `window.document_wave` | WaveDocument 实例 |
| `window.drawWaveform()` / `updateSidePanels()` / `mapCanvasPosition(x,y)` | 函数 |
| `window.document_wave.pushUndoSnapshot()` | ★ 核心自带，内部调用 32 次；自带撤销栈上限 100 + 清 redo 栈。**优先复用** |
| `window.document_wave.valueToLabel(value, radix)` | 按进制格式化标签；`window.Radix = {Hexadecimal:0, Decimal:1, Binary:2}` |
| `window.__wpf` | 前任自建的共享命名空间（`js/feature-common.js`）：`ready / canvas / mapAt / signalRowBand / currentBitState / bitStateToValue / setBitState / currentTool / pushUndoSnapshot / syncSignalMeta / scheduleRedraw / clamp / subSteps / stride / writeValue / editGranularity / busRadix / el / cursor / selection` |

`mapCanvasPosition` 返回字段：
`signalIndex, signal, clickedOnName, mainStep, subStepFraction, globalSampleIndex, signalSampleIndex, signalSubSteps, signalDivisor, signalEffectiveCount, nameWidth, relX, stepWidth, globalStepWidth`

- **返回 null 的唯一条件**：`if(!document_wave||!canvas)`。
  几何越界返回**全 `-1` 的哨兵对象，不是 null** —— 别写「越界会崩」的断言。
- 核心**无 DPR 缩放**（`devicePixelRatio` / `setTransform` 出现 0 次）。
