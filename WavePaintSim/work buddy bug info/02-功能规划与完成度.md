## 1. 原始功能规划（六阶段）

出自 `docs/绘图功能规划.md`，按优先级分期：

| 阶段 | 主题 | 内容 |
|---|---|---|
| **阶段一 P0** | 数据模型严谨性修复 | 1.1 添加信号长度对齐模型；1.2 画布→仿真采样规则；1.3 VCD/WaveDrom 导出严谨化；1.4 统一步数语义；1.5 子步数变化联动 |
| **阶段二 P1** | TimeGen 式鼠标绘制（用户点名） | 2.1 垂直位置决定 0/1；2.2 按住拖动连续绘制；2.3 保留 x/z/u/d 固定值模式；2.4 跨信号行自动切换 |
| **阶段三 P1** | 步数/子步自适应（用户点名） | 3.1 增大步数智能延续（时钟按周期、其它延续末值）；3.2 减小步数截断可撤销；3.3 子步数变化同步 |
| **阶段四 P2** | 编辑效率增强 | 4.1 键盘快捷键；4.2 选择工具批量操作；4.3 时间光标/测量；4.4 边沿对齐辅助 |
| **阶段五 P3** | 高级绘图 | 5.1 波形生成器；5.2 总线增强（进制/位字段/分组折叠）；5.3 模板片段库；5.4 信号层次树；5.5 缩放增强；5.6 导出增强 |
| **阶段六 P3** | 代码卫生 | 6.1 模块化；6.2 建立测试页；6.3 文档 |

**规划时的关键技术决策**（`docs/绘图功能规划.md` 第二节，请接手者遵守）：

| 方案 | 结论 |
|---|---|
| A. 直接修改混淆 JS | ❌ 字符串运行时解码、变量名混淆，无法安全编辑 |
| B. 一次性 TS/JS 全量重写 | ❌ 143 万字符，会丢失缩放/导出/分组/撤销栈等大量细节，回归成本极高 |
| **C. 新增独立 feature 模块 + 事件接管 + 原型覆写** | ✅ **已采用并严格执行** |

## 4. 缺失项详细说明

### 4.1 F9 总线信号增强（未实现）

**规划要求**：
1. 总线（Vector）信号显示进制切换 hex / dec / bin，切换即时生效并持久化；
2. 位字段标注（可选）；
3. 总线分组 / 折叠（可选，依赖原版 `groupName` 机制）。

**现状**：
- `Signal` 对象有 `radix` 字段，`model.js` / `app.js`（死代码）里有完整的 radix 处理逻辑，但**运行时链路里没有任何 UI 入口**去修改它。
- `sim-bridge.js` 创建信号时**硬编码** `radix: "hexadecimal"`（如 `readWaveDocument()` 第 344 行、`toNativeSignal()` 第 208 行），用户无法切换。

**实现建议**：
1. 找到混淆核心的属性面板（`#tool-properties` 按钮触发，`index.html:373`）与信号属性弹窗；
2. 新增 feature 模块，在弹窗中注入「进制」下拉（hex/dec/bin）；
3. 监听 change → 改 `signal.radix` → 用 `formatVectorValue(values[i], width, radix)` 重算 `labels` → `drawWaveform()`；
4. 导出/保存时确保 radix 被持久化（原版序列化若不含 radix，需在导出前补写）。

**风险**：取决于原版属性面板的 DOM 结构，需运行时探查。

### 4.2 F10.2 回归测试（未实现）

**现状**：仅 `backup/verify_hybrid.mjs` 一个一次性脚本（直接 `import` 源码、生成 TB、调本机 iverilog、检查 `q=0xA`），放在 backup 目录说明是临时产物。

**建议最小测试集**：
| 测试 | 断言 |
|---|---|
| 数据模型一致性 | `document_wave.m_signals.every(s => s.values.length === m_sampleCount*(m_subStepCount+1))` |
| F1 添加信号 | 步数30/子步1 点「添加信号」→ `values.length===60` 且全为 `-1` |
| F3 resize | `0101` 时钟 30步→50步，尾部延续 `0101`；50→30 截断回原样；子步1→2 长度 60→90 且主值不变 |
| F2 绘制 | 信号带上半点击 → `values[idx]===1`；下半 → `===0` |
| **TB 生成快照** | 给定画布波形，生成的 TB 文本与基线逐字符比对（把 `verify_hybrid.mjs` 改造为正式用例） |
| VCD 回填 | 给定 VCD，输出信号按 `tmax/timeSteps` 归一化采样正确 |

### 4.3 功能层脆弱性（规划未覆盖，但必须补）

**`feature-*.js` 全部假设混淆核心会一直暴露那 8 个全局 API**。一旦上游 WavePaint 更新、改名或 bundle 被 IIFE 包裹，`wpf.ready()` 会每 100ms 静默重试**永不报错**，8 个模块集体失效而用户只看到"功能没了"。

**建议**：在 `feature-common.js` 的 `ready()` 里加超时（如 10s）与缺失 API 清单提示，在页面显眼处（如仿真面板状态栏）输出诊断信息。详见 `04-BUG清单` BUG-017。
