原型交互说明

1. 停靠（Dock）

  • 按住面板标题栏拖动 → 出现蓝色落点框。
  • 拖到某个面板的上缘 / 下缘 / 左缘 / 右缘（约 26% 带宽）→ 在那一侧切分出新窗格。
  • 拖到某个面板的标题栏/Tab 栏或正中间 → 与之合并为 Tab 组。
  • 拖到整窗最外缘（22px 环带）→ 在工作区边缘新建一个区。
  • 按 Esc 取消拖动。

2. 尺寸

  • 拖两个窗格之间的分隔条调整比例（有最小尺寸保护）。
  • 波形面板内：拖「信号名列 / 波形区」之间的竖分隔条，可调名列宽度。

3. Tab 与浮出

  • 点 Tab 切换；Tab 上按中键 / 双击可浮出该面板。
  • 标题栏右侧按钮：⧉ 浮出 / ▣ 最大化 / ✕ 关闭。
  • 浮动窗可拖动、右下角可缩放、▣ 最大化到整个工作区、⤓ 收回停靠。

4. 布局预设与持久化

  • 布局菜单：仿真 / 编辑 / 审阅 三套预设；Ctrl+Alt+1/2/3 快速切换，Ctrl+Alt+0 重置。
  • 布局默认只写 session/localStorage，不写 .wp 工程存档（按用户裁决）。

5. 控件分层（第二十五轮 U0-R：顶栏统一）

  • L1 统一工具带（顶部，全应用唯一一条功能栏）：运行仿真（唯一主按钮）｜打开 / 保存｜撤销 / 重做 / 剪切 / 画笔颜色｜视图（缩小 / 放大 / 适应窗口 / 时间跳转）｜绘制（画笔 / 橡皮擦 / 选择）｜编辑状态（位状态 / 整步·子步 / Dec·Hex·Bin）｜标注（箭头 / 时间跨度 / 标记 / 文本标注）｜对象（添加信号 / 选择对象 / 属性）｜步数 / 子步数。
  • 波形面板内不再有子工具带：波形区的功能栏一律回到 L1 顶栏（第二十五轮拍板，回退第二十四轮的「面板上下文带」方案）。
  • 其余面板内的子栏只保留「本面板专属」动作（源码窗的打开 / 保存 / 解析 RTL / 生成 TB，层次树的展开 / 折叠，文件列表的添加 / 移除 等），不与 L1 重复。
  • L4 状态栏：左 服务与消息｜中 当前上下文（选中信号 / 当前文件 / 计数）｜右 布局与面板计数；长提示一律收在这里。
  • 窄窗口时，整组控件按优先级收进工具带右侧的 ⋯（不折行、不溢出）。

本原型仅用于评审「形态」：所有面板内容是假数据，不连接仿真服务、不影响现有 index.html 与 js/。
