WavePaint 原型（多面板 / 自由拖拽）— 操作说明

这一版在验证什么

  • 菜单栏 / 工具带 / 波形区 / 代码区 逐字照搬真机 index.html（同一份 DOM + 同一份 CSS + 同一份 JS）， 所以看到的就是真机效果，只是从「全屏」变成了「面板」。
  • 面板之间的停靠布局（Verdi 式多窗格）与自由拖拽（Word 式自由排布）是本原型新增的能力。

拖拽面板

  • 按住面板页签拖动：拖到另一面板的页签条 = 合并成一个 Tab 组；
  • 拖到某面板的内部边缘 = 在该侧切出新窗格（蓝框预览 = 松手后的真实位置）；
  • 拖到工作区最外缘（约 20px 环带）= 新建一整行 / 一整列；
  • 中键点击页签 / 双击页签 = 浮出为自由窗口；浮窗标题栏拖动可跨面板停靠。

分隔条与缩放

  • 拖动面板之间的分隔条调整比例；拖动浮窗右下角调整浮窗大小。
  • 窗口尺寸变化时画布自动重绘（画布等价于真机画布）。

底部状态栏（原型独有）

  • 布局 ▾ 切换三套预设（仿真 / 编辑 / 审阅）或保存 / 清除布局；
  • 面板 ▾ 逐面板显示 / 隐藏 / 浮出 / 收回；
  • Ctrl+Alt+1/2/3 切预设，Ctrl+Alt+0 恢复默认，Esc 取消拖动 / 关闭菜单。

与真机的差别（有意为之）

  • 没有本地仿真服务：点「运行仿真」不会真的跑 iverilog，也不会拉起真机 exe（原型已禁用协议唤醒）。
  • 「控制台 / 源文件 / 端口」三块面板真机没有，内容是原型假数据，用来演示更多窗格形态。
布局改动会自动存进 localStorage（键名 wavepaint.mock.layout.v1），刷新后保留。 想回到出厂状态：布局 ▾ → 恢复默认布局。
