### 2.2 `js/sim/panel-layout.js`（新增，约 520 行，LF 无 BOM）

唯一导出 `installSimPanelLayout({panel, body, handle, storageKey, onLayout})`，返回
`{getState, setWidth, reset, destroy}`；**缺任一 DOM 节点返回 `null`，走 CSS 兜底**。

- **折叠**：点 `.sim-card-head[data-sim-card-toggle]` 切换卡片 `.collapsed` + `aria-expanded`；
  标题行内的 `button/a/input/select/textarea/label` 点击**不触发折叠**（保护 `#sim-tb-copy` 等控件）。
- **像素权重高度**：`flex-grow = 权重/总权重*100` + `flex-basis:0`（默认 `{source:300, rtl:245,
  vcd:245, tb:190}`），卡片按权重分配面板可视高。
- **`measureMinHeight` / `applyMinHeights`**：`min-height = min(实测内容高, 面板可视高*0.8)`
  （常量 `MIN_BODY_PX=24`、`MIN_CARD_CAP_RATIO=0.8`），在 `commit()` / 初始装配 / `setWidth()` /
  `window resize` 均重算。
- **splitter**：`pointerdown` → `resizePair` 在相邻两卡间重分配权重，`body.sim-resizing` 关过渡；
  相邻卡折叠时该 splitter 加 `.disabled`；拖拽时 rAF 节流派发 `window` `resize`。
- **宽度**：`setWidth(px)` clamp `280 ~ min(760, 视口*60%)`，写 `--sim-panel-w`。
- **持久化**：**只走 `sessionStorage`**，key `wavepaint.sim-panel-layout.v1`，
  载荷 `{v:1, w:{}, c:{}, width}`，220ms 防抖。**绝不写进 `.wp` 工程存档。**
- **键盘可达**：splitter `ArrowUp/Down` ±16px、`#sim-resize-x` `ArrowLeft/Right`。

## 三、本轮修掉的真 bug（重点）

### 现象

`.e2e-tmp/verify-recovery2.mjs` 的 D1/D1b 失败：点 `#sim-run` 后仿真不启动，
状态栏停在「暂无仿真结果」。

### 根因

headless Edge 默认视口 **750x485**；四卡按权重分配后**源码卡只剩 80px**，而
`.source-toolbar` 实测 **170px**（`.source-actions` 9 个按钮 grid 折行后高 134px）
→ 被 `overflow` 裁掉 → 坐标点击 `#sim-run`（中心 y=342）落到 **VCD 卡**上
→ **仿真根本不触发**。

> 这也解释了用户反复报的「点仿真无响应」：**不是服务问题，而是按钮被裁掉后点不到**。

### 修复

`measureMinHeight` / `applyMinHeights`（源码卡在 750x485 下 `min-height=272px`）
+ `.sim-panel-body{overflow-y:auto}` + `#sim-status{position:sticky;bottom:0}`。

### 验证

`.e2e-tmp/verify-recovery2.mjs` **17/17** 全过（修复前 D1/D1b 失败）。

## 五、关键结论（交给下一位 AI）

1. **契约面零改动是硬约束**：DOM 事实上就是 e2e 的测试接口（e2e-rtl 28 处 CSS 选择器依赖、
   e2e-ui 86 项）；本轮新增的 `[data-sim-card]` / `[data-sim-split]` / `.sim-card*` /
   `.sim-panel-body` / `#sim-resize-x` 全是**新增**，不属冻结面。
2. **面板状态绝不进 `.wp`**：只走 sessionStorage（`wavepaint.sim-panel-layout.v1`）；
   `.wp` 里只应有 #76 B5 的 `simWatches` 元数据。理由见 07 D20 否决项 3 / D21。
3. **`measureMinHeight` 不是冗余代码**：它是「矮窗口按钮被裁 → 点仿真无响应」的修复，
   动它之前先跑 I8 与 `.e2e-tmp/verify-recovery2.mjs`。
4. **层次树左置是用户明确暂缓项**，侧栏保持右侧、整体骨架不动，除非用户再次拍板。
5. **下一步 = 08 §2.6「⏳ 剩余（可选/暂缓）」**：VCD 树移入波形区 / TB 控制带收敛 /
   层次树左置；开工前先与用户确认范围与优先级。
