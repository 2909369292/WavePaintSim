## 做了什么

- `lib/codemirror.bundle.js`（305KB）：`tools/cm6-entry.js` 经 esbuild 预打包成 IIFE，挂 `globalThis.WPCm`，导出 `createVerilogEditor`；`package.json` 增 devDeps（codemirror / @codemirror/legacy-modes / esbuild），`allowScripts` 放行 esbuild 安装脚本。
- `js/sim/rtl-nav.js`（纯函数）：复用 `engine.parseVerilogDesign()`，为 module/port/parameter/instance 定位「文件 + 行号」；`blankComments` 把注释抹成等长空格（保留换行），保证行号按原文、注释中的 module 字样不干扰。
- `js/sim/vcd-index.js`（纯函数）：`buildVcdHierarchy(parsed)` 沿点分 scope 建链，输出 `{signalCount, scopeCount, tree}`，纯数据树可 JSON 序列化，根作用域信号挂 root。
- `js/sim/rtl-panel.js`（DOM 渲染层）：`installCodeEditor`（CM 挂载 + textarea 数据镜像 + 缺失降级）、`renderRtlTree`（点击 → onJump）、`renderVcdTree`（点击信号 → onSignalPick(完整路径)）；不 import ui-bridge 防循环依赖。
- `index.html` + `ui-bridge.js`：仿真面板新增代码视图 / RTL 树 / VCD 树卡片；`initSourceCodeView` / `setEditorText` / `jumpToEditorLine` / `refreshStructureTrees` / `refreshVcdTree`；`state.vcd` 保存最近一次成功仿真的 `parseVcd` 产物；编辑防抖 350ms 重建 RTL 树；切文件/程序性写销毁重建 EditorView（防 Ctrl+Z 跨文件回滚）。
- `tools/e2e-rtl.mjs`：新增 #75 浏览器级冒烟（真实 Edge + dev-server，9 项 A0~C3）。
- `tools/regression.mjs`：新增 rtl-nav（5 项）+ vcd-index（4 项）纯函数用例，49 → 58。

## 关键结论

- CM 不可用时 textarea 自动 fallback，`installCodeEditor` 返回 `active=false` 并隐藏 CM host —— 任何旧路径零影响。
- 用户编辑 onChange 同步回 textarea（`syncEditor()` 旧读路径兼容）；`setEditorText` 永不双写。
- VCD 信号完整路径 = `node.path + "." + signal.name`，已按真实 `parseVcd` 产物验证。
- ANSI 头部多行端口行号逐行精确；共享方向关键字单行列表（`input a, b`）同列定位；非 ANSI 定位到体内方向声明行。
