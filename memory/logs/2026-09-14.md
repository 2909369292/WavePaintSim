  ```js
  let vcdText = text, simLogText = "";
  if (text.startsWith("@@LOG:")) {
    const cut = text.indexOf("@@VCD:");
    simLogText = (cut >= 0 ? text.slice(0, cut) : text).replace(/^@@LOG:\r?\n?/, "");
    vcdText = cut >= 0 ? text.slice(cut + "@@VCD:".length).replace(/^\r?\n/, "") : "";
  }
  for (const logLine of simLogText.split(/\r?\n/)) {
    const line = logLine.replace(/\r/g, "");
    if (!line.trim()) continue;
    consoleOut(line, /error/i.test(line) ? "error" : (/warning/i.test(line) ? "warn" : "info"));
  }
  vcdToProjectOutputs(vcdText, project);   // 无 @@LOG: 前缀 = 旧格式整体当 VCD
  ```

### 关键结论

1. **成功路径也必须回文本**：第 39 轮之前成功路径只回 VCD 文本，`iverilog` 的 warning 与 `$display` 输出**全部被丢弃**；
   要满足「编译不过把报错打进来」，就必须让成功路径也带日志 → `@@LOG:` 段
   （**只有这个前缀才分段**，别的都按旧格式整体当 VCD）。
2. **Windows 换行是 CRLF**：`iverilog` / `vvp` 在 Windows 上输出 CRLF，切行必须 `/\r?\n/` + 逐行 `replace(/\r/g,'')`，
   否则每行尾巴会拖一个 `\r`（表现为行末小方块 / 缩进错位）。
3. **`#sim-status` 是单行元素**：把多行内容塞进去会挤成一坨 → 一律先 `firstLine()` 截首行；多行只走日志流（06 P50）。
4. **`.mk-cline` 是计行契约**：`dock-probe.mjs:128` 靠它统计日志行数，改名会静默打断停靠回归。
5. **`?dock=off` 逃生口仍要日志**：日志皮肤从 `body.wp-dock` 提出去变全局 + §6 垫片（**不能 `display:none`**）。
