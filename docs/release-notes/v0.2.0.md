# v0.2.0 Release Notes

发布日期：2026-08

## 概览

本版本修复了"点击 Sim 后结果恒为 0"的核心仿真缺陷（四层根因全部修复），并加入一批绘图增强功能模块（`feature-*.js`）。此前所有预置波形下仿真结果为 0 的问题现已验证解决（counter 例程输出 `q=0xE`）。

## 仿真修复（四层根因）

| 层 | 根因 | 修复 |
|----|------|------|
| 1 | `feature-draw.js` 被改出双引号语法错误，模块加载失败 | 修正语法 |
| 2 | TimeGen 仅 `paint` 工具时接管，默认无工具时不接管 → 落回原版写子步奇数下标 | 无工具时也接管（`tool !== 'paint' && tool !== null` 时 return） |
| 3 | `readWaveDocument` 只采主值偶数下标，画在奇数下标采不到 | `sampleMainValue`：主值为 x 时取步内第一个确定值 |
| 4 | 未绑定端口共用 fallback，导致激励错乱 | `matchSignalsToPorts`：name→fuzzy→unbound；unbound 输入生成默认全 0 |

## 新增功能

- **TimeGen 式绘制**：信号带上半区画 1、下半区画 0，按住拖动连续绘制
- **Auto RTL**：自动识别 RTL 输入端口并添加到画布
- **编辑力度**：整步 / 子步切换
- **总线进制**：Dec / Hex / Bin 切换
- **波形生成器**：正弦、三角、锯齿、随机、毛刺时钟
- **协议模板**：SPI、I2C、UART 读写时序
- **测量光标**：Alt+点击 A/B 双光标
- **框选批量**：设 1 / 设 0 / 翻转 / 复制 / 粘贴
- **快捷键**：1/0/X/Z/U/D、方向键绘制、Ctrl+Z/Y

## 其他改进

- 数据模型对齐：信号长度 = 步数 × (子步+1)，添加信号长度正确（30 步 → 60）
- 单实例保护（Mutex）+ 仿真期间不退出（simBusy）
- 界面乱码修复、F7/F8 波形生成器/协议模板菜单补齐
- 新增回归测试 `tools/regression.mjs`（33 项黄金快照）

- 拖动锁定信号（TimeGen 行为）需 drag.signalIndex + paintMove
