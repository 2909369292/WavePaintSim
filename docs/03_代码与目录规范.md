# 代码与目录规范（WavePaintClean）

> 目标：目录即职责；文件名即模块；新代码必须按此规范写，旧代码随迁移对齐。

## 1. 目录分层（已落地）

```
js/
  wavepaint.clean.js         解混淆核心（黑盒底线；行为 = 原混淆核心，已验证）
  core/                      核心桥接与共享适配
    __core.js                官方桥接 window.__core（editor/sim 唯一允许访问核心的入口）
    wpf.js                   历史共享层 window.__wpf（迁移中，最终并入 __core/editor 各域）
  editor/                    画布编辑域（原 feature-*.js）
    draw.js / selection.js / value-input.js / shortcuts.js /
    measure.js / resize.js / generator.js / templates.js
  sim/                       仿真后端 + 面板桥
    engine.js                Verilog 解析 / 激励 / Testbench / VCD（纯逻辑，可单测）
    project-model.js         波形数据模型 / 项目存取 / 值格式化（纯逻辑）
    ui-bridge.js             仿真面板 UI 桥接（唯一直接操作 DOM 的 sim 层）
  util/                      与域无关的工具
    id.js                    uid / deepClone / clamp
```

## 2. 命名规范

### 2.1 文件
- 小写连字符（kebab-case），**无 `feature-` 这类工程前缀**
- 目录内文件是"名词/动作"：`draw.js`、`selection.js`、`value-input.js`
- ESM 模块用语义名：`project-model.js`（数据模型）、`engine.js`（纯逻辑引擎）

### 2.2 全局命名空间（唯一 3 个，禁造新的）
| 命名空间 | 归属 | 用途 |
|----------|------|------|
| `window.__core` | js/core/__core.js | **editor/sim 访问核心的唯一通道**（state/selection/redraw/…） |
| `window.__wpf` | js/core/wpf.js | 历史共享层（迁移期间兼容；新代码一律用 `__core`） |
| `window.__wpfVec` | sim/project-model.js | 值格式化/归一化（普通 script 用） |

禁止在其它文件向 window 挂新全局；必须暴露时经 __core 登记。

### 2.3 模块导出
- ESM（sim/ util/）：显式具名导出；一个文件一个域（engine 拆得太碎反而难读时可保留，但顶部注释分节）。
- 普通 script（core/ editor/ patch/）：IIFE + `window.__wpf.ready(fn, 名称)` 注册，
  顶部注释写明"依赖/就绪条件"。

### 2.4 函数/变量
- 布尔开关用 `isXxx`/`hasXxx`；事件回调前缀 `on`；私有函数不导出、同名加 `_` 前缀注释说明。
- 魔法数字必须命名常量（如 `stride = m_subStepCount + 1`、Bit 编码值 → `__core.Value`）。
- 核心状态一律经 `__core.state()` 读、经 `__core.*` 写，禁止散布 `rangeSelActive` 这类名字。

## 3. 数据模型口径（C1，防历史"口径不一致"翻车）

```
主步 m_sampleCount；子步 m_subStepCount；stride = m_subStepCount + 1
sig.values 长度 = 主步数 × stride（线性布局；整步写 = 铺满 stride 格，子步写 = 单格）
Bit 编码：0/1/-1(x)/2(z)/3(u)/4(d)（__core.Value）
Vector：位串字符串，长度 = width
读写统一走 editor/granularity 的写原语或 sim/project-model 的换算；新代码禁止自推 stride。
```

## 4. 依赖方向（禁止反向）

```
editor ──> core(__core/wpf) ──> wavepaint.clean.js
sim ──> util(id.js) + project-model
editor ──> 只读 document_wave（经 __core）
任何域都不得直接抓 clean.js 的内部标识符（魔法名）；确有需要 → 在 __core 登记。
```

## 6. 回归门槛（每步必跑）
- `node tools/regression.mjs`（35 项逻辑/快照）

- `node tools/e2e-ui.mjs`（真实 Edge + 源码服务：valueToLabel / 单信号进制 / 值输入弹窗流，19 项）

- UI 改动需用户人工验收

## 6b. 弹窗与进制标签（PATCH 收敛进核心后）
- **弹窗唯一入口**：`__core.prompt` → 核心 `wpQuickPrompt`（快速录入：回车/有值失焦=提交、
  空值失焦/Esc/X/遮罩=取消、非法输入红框重开）。外部模块（value-input.js）不再碰弹窗 DOM。
- **标签唯一实现**：核心 `WaveDocument.valueToLabel`（[PATCH-A3]：位串按位宽换算、去 0x/0b
  前缀、-1→X、x/z 位串→X/Z；数字值走 toString(radix)）。外部统一 `wpf.valueLabel` 转发，
  `wpf.refreshBusLabels` 只做「按信号自身 radix 批量重算」。
- 已删除：原型补丁 patchCoreValueToLabel、zh.js DOM 拦截、MutationObserver 弹窗抑制器、
  value-input 自驱弹窗 DOM（80+ 行）。
