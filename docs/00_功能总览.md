# WavePaintClean 功能总览

> 合并 WavePaintSim（原混淆核心 + 扩展）与 WavePaintClean（解混淆核心）后的功能全景。
> 分层归属：**核心**（解混淆核心自带，行为已验证与原版 1:1）、**扩展**（重构后新增/改进层）、
> **仿真**（后端管线）。本文档是重构期功能基线——重构不得改变下述行为。

---

## 1. 画布与波形编辑（核心自带 + 扩展增强）

### 1.1 数据模型（后端存储/编辑核心）
- `document_wave`（`WaveDocument` 实例）：
  - `m_sampleCount`：主步数；`m_subStepCount`：每主步子步数；
    `stride = m_subStepCount + 1`（每主步占的下标数）
  - `m_signals[]`：信号列表，每项含 `name / type(Bit|Vector) / values[] / width /
    radix / clockMarkers` 等
  - `values` 编码：Bit 用数字 `0=低,1=高,-1=x,2=z,3=u,4=d`；Vector 用位串字符串
    （长度 = width）
  - `values.length = m_sampleCount × stride`（主步 × 子步对齐的线性布局）
  - 信号间允许不同 values 长度（可裁剪/扩展）
- 撤销/重做：`document_wave.pushUndoSnapshot()/undo()/redo()`
- 时钟标注：`clockMarkers[]`（画时钟沿时标记该下标为沿）

### 1.2 原版画布功能（核心）
- 信号列表：添加/删除/排序/改名/信号行拖拽移动
- 每种信号的绘制（Bit 沿、Vector 总线、箭头、时间跨度、标记、文本标注）
- 时间缩放/平移（滚轮/工具），主步/子步网格渲染
- 工具栏：打开/保存（JSON）、撤销/重做、剪切/复制/粘贴、放大缩小适应
- 位状态工具（Bit 逐格绘制、自动 Bit 模式）、右键菜单（进制转换、Bit/Vector Value）
- 主题 light/dark（`applyTheme`）
- 属性面板（信号宽度/名称等）

### 1.3 扩展编辑层（重构来源 feature-*.js）
| 模块 | 功能 |
|------|------|
| **TimeGen 式绘制** | 画笔工具下按住左键拖动画 1、按住右键/下移画 0（或配置），支持橡皮擦；快速拖动**插值补齐**跨过的所有格子（整步按主步、子步逐格） |
| **编辑粒度** | 顶部「整步 / 子步」开关：整步 = 一次写入/框选覆盖整个主步（stride 格）；子步 = 精确到子格。控制写入、框选视觉、翻转、值输入全部路径 |
| **值输入编辑** | 点 Bit 格弹「Bit Value」；点 Vector 格弹「Vector Value」；支持直接输入 `0/1/x/z`、位串 `1010`、`0xA`、`8'hA5`、`x` 等；回车/点击别处即写入，不输入即取消 |
| **框选 + 批量** | select 工具拖动/单击框选（范围按粒度对齐）；工具条：设 1/设 0/设 x/翻转/输入值；选框视觉与菜单同步出现/消失；点击别处清除选框 |
| **键盘快捷键** | 方向键移动并绘制 1/0；Ctrl+Z/Y 撤销重做；Delete 清格等 |
| **步数/子步自适应** | 改变步数/子步数后自动伸缩各信号 values 并保留波形形状（插值/截断），时钟沿标记同步 |
| **波形生成器** | 一键生成典型波形：时钟、计数器、脉冲、单拍、PWM、复位、随机等 |
| **时间光标测量** | 画布上移动时间光标，显示当前时间/值；测量两点间 span |
| **协议模板库** | SPI / I2C / UART / AXI 等常见协议波形插入画布 |
| **总线进制** | 顶部 Dec/Hex/Bin 开关；单信号右键可独立设进制；总线标签按信号自身 radix 显示（不带头 0x/0b）；核心 valueToLabel 行为经统一口径校正 |
| **光标状态** | 记录当前画位置，供多处 UI 同步 |

## 2. 仿真子系统（自研，不依赖核心内部）

```
Verilog 源码 ──parseVerilogDesign──▶ 设计模型(design: ports/instances/params)
                                         │  syncProjectSignalsToDesign
  画布 signals ◀──vcdToProjectOutputs───┤  createPortStimulus / typicalWaveform
        ▲                 VCD           │  buildAutoTestbench
        │                               ▼
  画布激励(项目) ──readWaveDocument──▶ 画布波形数据 → Testbench(Verilog)
                                          │
                                buildSimulationPayload @@FILE 载荷
                                          ▼
                           后端 /api/sim（exe 内 C# 或 dev-server Node）→ iverilog+vvp → VCD
```

### 2.1 设计解析（sim.js）
- `parseVerilogDesign(source)`：完整解析 module 头/端口方向、声明、参数、实例化
- 输入输出自动识别（input/output/inout/reg/wire）、位宽推导
- `createPortStimulus`：每个输入端口生成典型激励（时钟名自动交替、复位脉冲、使能等）
- `typicalWaveform`：输出端口的示例波形（供预览/演示）

### 2.2 测试台生成（sim.js / sim-bridge.js）
- `buildAutoTestbench(design, project)`：由**画布当前波形**直接生成 Verilog 测试台
  - 主步级驱动：每主步写一次端口值；时钟（位宽 1）按**每格序列**用 `#(k/stride)`
    分数时间逐格驱动（画布显示什么就仿什么）
  - 复位信号自动补上电复位脉冲（避免全 x 时输出恒 x）
- `buildSimulationPayload(files, tb)`：打包成后端 `@@FILE:` 载荷

### 2.3 仿真运行（sim-bridge.js）
- 面板：源码多文件管理（+/- 文件）、解析、添加信号（输入端口进画布做激励）、
  运行仿真、Testbench 预览、一键复制 TB
- 画布→TB：`readWaveDocument()` 读取画布当前全部激励波形（含粒度布局 stride）
- 后端抽象：exe 内嵌 C# HttpListener `/api/sim`，或 dev-server 的 Node `/api/sim`，
  协议一致；返回 VCD 文本
- 结果回填：`vcdToProjectOutputs` 把仿真输出（q、count 等）映射回画布作为
  结果信号（可覆盖/对比）

### 2.4 结果诊断
- `diagnoseSimulation`：激励未绘制（全 x）/无时钟/结果恒 0 等常见问题提示
- 状态显示（`sim-status`）与超时保护（30s）

## 3. 交互与集成层

- `__wpf`：核心全局 API 访问命名空间（现在很多成员是「补丁」，重构后收敛到 `__core`）
- 多脚本就绪协调：`wpf.ready(回调, 名称)`（DOM + 核心加载完成后执行）
- `#wp-modal`：核心通用输入弹窗（被扩展复用为 Bit/Vector Value 输入载体）

## 4. 打包 / 运行形态

- 浏览器开发：`node tools/dev-server.mjs <port>`（含 Node `/api/sim`）
- 独立 exe：`build.ps1` 打包全部前端 + iverilog 便携包 → 本机 HttpListener +
  自动开 Edge `--app=`；单实例；`/api/sim`、`/api/snapshot`、`/api/ping`
