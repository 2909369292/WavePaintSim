## 1. 必读背景（压缩版）

### 1.1 数据模型铁律

```
每个 Signal.values.length === m_sampleCount × (m_subStepCount + 1)
每个主步占 stride = (子步+1) 个下标；主值 = 下标 mainStep×stride（仿真采样取这个）
```

### 1.2 架构原则

- **禁止改**混淆核心 `js/wavepaint.63e6dade.js`；所有功能在 `js/feature-*.js` + `index.html` 实现。
- 改 JS/HTML 后**必须重建 exe**（`build.ps1`）才生效。
- `js/app.js` / `renderer.js` / `utils.js` 是**死代码**（另一套被放弃的 Canvas 实现，从未被 index.html 加载），不要改；可清理（BUG-015）。
- `js/sim.js` / `model.js` 被 `sim-bridge.js` import，**是活代码**。

## 2. 待实现 / 待修复（按优先级）

### 🔴 P0 正确性（直接影响仿真结果，必须先修）

#### P0-1 BUG-002：未绑定端口共用 fallback 信号 → 仿真静默错误

**文件**：`js/sim.js:477-489`（`matchSignalsToPorts`）
**根因**：第 486 行 `(signals||[]).find(s => s.role !== "result")` 对每个未匹配端口都返回**同一个**第一个信号。当 RTL 端口数 > 画布信号数时，多余端口被同一个信号驱动，TB 合法但激励错误。
**修复方案**：
- 若 `exact` 未命中，**不 fallback 到已用信号**，改为返回 `{ port, signal: null, matched: false, strategy: "none" }`。
- `buildAutoTestbench` 里对 `signal === null` 的端口：输出端口声明 `wire`（不驱动）；输入端口**用一个"恒 0 占位"**或提示用户（推荐：输入端口生成一个全 0 的默认激励，并在 module-preview 醒目提示"端口 xxx 无匹配信号，使用默认 0"）。
- 具体：在 `matchSignalsToPorts` 返回前，对 `strategy === "none"` 的输入端口，从 project 构造一个 `{ name: port.name, kind, width, values: 全 "0" }` 的默认信号（用 `createSignalFromPort`），避免共用。
**验收**：RTL 有 5 端口、画布只有 clk/rst_n → TB 里其余端口是独立默认值（不是 clk 波形），且仿真结果不再"被 clk 驱动"。

#### P0-2 BUG-003：TimeGen 绘制 / 方向键绘制无法撤销（实测确认）

**文件**：`js/feature-draw.js`（onMouseDown / paintAt）、`js/feature-shortcuts.js`（方向键写入）
**根因**：feature 模块在 mousedown 捕获阶段 `stopImmediatePropagation` 阻止了原版处理（原版可能在按下时压撤销栈），而 feature 自己没压栈。
**修复方案**：
- `feature-draw.js`：在 `onMouseDown` 首次按下（`drag.active = false` → `true`）时，**调用一次 `wpf.pushUndoSnapshot()`**（feature-common 已提供），之后同一次拖动内的连续写入共用这一个快照。
- `feature-shortcuts.js`：方向键写入前调用 `wpf.pushUndoSnapshot()`（节流：可每次按键前压）。
- 注意：`pushUndoSnapshot` 里 `structuredClone` 对 `Signal` 实例会丢原型（BUG-007 关联），改用 `JSON.parse(JSON.stringify(...))` 或深拷贝修正（见 P2-4）。
**验收**：TimeGen 画一笔 → Ctrl+Z 恢复；方向键画一笔 → Ctrl+Z 恢复；不影响其它原版撤销。

### 3.1 TimeGen 绘制：写整主步 + 锁定信号 + 撤销（合并 P0-2 / P1-1）

```js
// feature-draw.js 核心（示意）
const drag = { active: false, signalIndex: -1, value: 1 };

function paintRange(sig, mainStep, stride, value) {
  const start = mainStep * stride;
  const end = Math.min(start + stride - 1, sig.values.length - 1);
  for (let i = start; i <= end; i += 1) sig.values[i] = value;
}

function paintAt(e) {
  const hit = hitTest(e);
  if (!hit) return;
  const sig = window.document_wave.m_signals[hit.signalIndex];
  const stride = (wpf.subSteps ? wpf.subSteps() : 0) + 1;
  if (wpf.editGranularity() === 'substep') {
    sig.values[hit.sampleIndex] = hit.value;
  } else {
    paintRange(sig, Math.floor(hit.sampleIndex / stride), stride, hit.value);
  }
  // 清时钟标记（同样按力度）
  ...
  window.__wpf.cursor = { signalIndex: hit.signalIndex, sampleIndex: hit.sampleIndex };
  wpf.scheduleRedraw();
}

function onMouseDown(e) {
  if (e.button !== 0) return;
  if (wpf.currentTool() !== 'paint') return;
  if (e.target !== wpf.canvas()) return;
  if (!wpf.isAutoBitMode() && !e.shiftKey) return;
  const hit = hitTest(e);
  if (!hit) return;
  e.stopImmediatePropagation();
  e.preventDefault();
  drag.active = true;
  drag.signalIndex = hit.signalIndex;   // ★ 锁定信号
  drag.value = hit.value;
  wpf.pushUndoSnapshot();               // ★ 压撤销栈（P0-2）
  paintAt(e);
}

function paintMove(e) {                 // ★ 拖动只影响锁定信号（P1-1）
  const m = wpf.mapAt(e.clientX, e.clientY);
  if (!m) return;
  const sig = window.document_wave.m_signals[drag.signalIndex];
  if (!sig || !isPaintableSignal(sig)) return;
  const stride = (wpf.subSteps ? wpf.subSteps() : 0) + 1;
  const mainStep = m.mainStep;
  if (mainStep < 0 || mainStep >= window.document_wave.m_sampleCount) return;
  if (wpf.editGranularity() === 'substep') {
    const idx = m.signalSampleIndex;
    if (idx >= 0 && idx < sig.values.length) sig.values[idx] = drag.value;
  } else {
    paintRange(sig, mainStep, stride, drag.value);
  }
  window.__wpf.cursor = { signalIndex: drag.signalIndex, sampleIndex: mainStep * stride };
  wpf.scheduleRedraw();
}

function onMouseMove(e) {
  if (!drag.active) return;
  e.stopImmediatePropagation();
  e.preventDefault();
  paintMove(e);
}
```

export function matchSignalsToPorts(signals, ports) {
  const signalMap = new Map();

## 5. 常见坑（速查）

1. csc 是 .NET 4.0（C# 4.0），改 C# 禁止 `out int x`、`??=` 等 C#7+ 语法。
2. **改 JS/HTML 必须重建 exe**；构建前先杀 WavePaint 进程（exe 被占用报 CS0016）。
3. **禁止改混淆核心**；一切走 `window.document_wave` / `window.mapCanvasPosition` / 事件接管。
4. 数据模型铁律：`values.length === 步数×(子步+1)`；绘制默认写整主步（保证仿真采样）。
5. 位值编码：Bit=数字(0/1/-1/2/3/4)，Vector=字符串。
6. **字符串引号**：JS 里字符串用**单个单引号** `'...'`，注意别写成 `''...''`（本次仿真 0 的根因就是双引号语法错误）。
7. 页面不可见时 `requestAnimationFrame` 不执行（feature-measure 的 overlay 依赖它）。
8. `#sample-spin`/`#substep-spin` 已由 `feature-resize.js` 接管，勿重复拦截。
9. `sim-bridge.js` 的 DOM id 勿改（只改样式）。
10. 中文一律 UTF-8 无 BOM；用 `[System.IO.File]::WriteAllText(path, text, (New-Object System.Text.UTF8Encoding($false)))` 写，别用 `Set-Content`。
