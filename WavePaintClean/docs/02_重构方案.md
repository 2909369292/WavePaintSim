# 重构方案（目标架构与分阶段路线）

> 原则：① 行为 1:1 不变（每步回归）；② 解混淆核心可持续再生成，核心内部修改走
> 「补丁段」；③ 对外稳定入口 `window.__core`，杜绝直接抓内部名字；④ 后端（波形
> 存储/编辑/仿真）与 UI 分层，方便后续加功能。

---

## 目标目录（js/ 内重组）

```
js/
  wavepaint.clean.js          解混淆核心（可重跑生成；内部补丁段见下）
  core/
    __core.js                官方桥接：收敛顶层内部名 → window.__core.*（只读快照+语义方法）
    core.patch.js            对核心的「干净补丁段」（A1~A6 的官方实现，同顶层作用域直改）
  editor/                    （原 feature-* 重组，去掉全部事件伪造）
    granularity.js           编辑粒度 + 波形写原语（对齐 C1）
    pointer-draw.js          画笔绘制 + 拖动插值
    selection.js             select 工具框选（直连核心 rangeSel* 状态）
    value-prompt.js          Bit/Vector 输入流（__core.prompt 统一弹窗入口）
    bus-radix.js             进制标签（改核心内，外只剩 UI）
    resize.js / generator.js / measure.js / templates.js / shortcuts.js
  sim/
    verilog.js               （sim.js 解析部分）
    testbench.js             （TB 生成 + 激励构建 + 复位脉冲）
    vcd.js                   （VCD 解析 → 画布输出）
    runtime.js               （后端调用抽象 /api/sim + 超时 + 诊断）
    panel.js                 （仿真 UI 编排，原 sim-bridge 精简）
  util/
    id.js                    （唯一 id）
    format.js                （值格式化/进制标签/编解码）
```

`index.html` 相应改 script/module 引用；`build.ps1`/launcher 自动包含新子目录
（需要把内嵌清单从 `js\*` 扩为 `js\**` 递归）。

## 分阶段路线（每阶段结束都构建 + 回归）

### Phase 0（已完成）
- 建立 WavePaintClean 为主项目，并入 docs/tools；回归 34/34。
- 确认 clean.js 顶层作用域开放（323 function + 核心状态全局可访问）→ 重构可行性。

### Phase 1：官方桥接 `__core` + 核心补丁段落地
1. `core/patch.js`：先在核心尾部把「A 类」改为官方实现，验证可直接改核心。
   - A3/A4：修核心 `valueToLabel` + 进制刷新（删原型补丁）
   - A2/A5：`wpPrompt` 统一入口 + 翻译（删 MutationObserver / DOM 拦截）
   - A1：暴露选框设置/清除语义 API（`__core.selection.setRange/clear`），
     由核心内部直改 rangeSel* + drawWaveform
2. `core/__core.js`：把扩展需要的内部名收敛为 `__core.*` 语义方法。
3. feature 侧先**新增调用路径**（不删旧）做 A/B 对照回归，确认行为一致后删旧。

### Phase 2：editor/ 重组（去合成事件）
- selection.js 用 __core.selection 直连；删除 dispatchAt/dispatchRaw/replaying/
  clearCoreSelection/方向感知等整层事件伪造。
- value-prompt.js 用统一弹窗入口；删除切 select 工具 hacks。
- granularity.js 承载 C1 写原语。

### Phase 3：sim/ 与数据层整理
- C1 数据模型 API：`wave.get/set`（主步/子步/粒度/时钟标记）、编解码、readWaveDocument
  等价语义统一。
- sim/ 拆模块；panel.js 只做 UI 编排。

### Phase 4：清理与收口
- 删除全部已迁移旧文件；注释规范；docs/00~02 更新为最终形态。
- 全量回归 + exe 重建 + 端到端（浏览器 + exe）。

## 回归门槛（沿用）
- `node tools/regression.mjs`：34 项（新功能加对应项）
- `node tools/e2e-sim.mjs`：0 失败
- 浏览器 e2e：画布像素 hash（核心改动必跑）+ 交互（单击/框选/翻转/值输入/两次仿真）
- UI 类改动需用户人工验收

## 风险与对策
| 风险 | 对策 |
|------|------|
| 改核心引入行为偏移 | 核心改动全部走补丁段 + 像素级 e2e 对比 |
| 合成事件删除后框选时序回归 | Phase 2 每删一层就浏览器验证一次 |
| 拆分文件破坏 module/script 加载 | index.html 加载清单一次性改完并 build+exe e2e |
| 历史功能遗漏 | 以 docs/00 功能总览为基线逐项核对 |
